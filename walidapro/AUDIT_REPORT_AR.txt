فحص شامل للـ OCR / Diacritization / TTS Pipeline
تاريخ الفحص: 2026-08-20

تم فحص 27 ملف Python والتحقق من Syntax/AST/compileall.

أهم نقاط الأمان والجودة في النسخة النهائية:
1) Final text-only reviewer لا يعمل افتراضياً داخل run_full_pipeline.py.
   السبب: لا يوجد لديه دليل بصري، وبالتالي لا يجوز أن يغيّر حروفاً أو أسماء تلقائياً.
   يمكن تشغيله يدوياً فقط بالـ flag: --enable-final-context-review

2) pipeline.py:
   - Candidate بلا دليل سياقي -> REVIEW، لا اختراع مرشح.
   - أي تغيير حروف يحتاج Gemini Visual مستقل.
   - Gemini UNCLEAR لا يمكنه إنتاج ACCEPT.
   - Visual/cache و Reviewer/cache لتجنب إعادة API لنفس الحالة.
   - اختيار القراءة البصرية أصبح محايداً بين original/candidate.

3) lighton_ocr.py:
   - فحص variants أصبح adaptive.
   - يبدأ باثنين ويوقف مبكراً عند اتفاق قراءتين، بدلاً من 5 requests دائماً.

4) visual_reviewer.py:
   - طلب بصري واحد للحالة.
   - confidence < 0.72 -> UNCLEAR.
   - قراءة غير كلمة عربية واحدة -> UNCLEAR.
   - تقارب original/candidate -> UNCLEAR.
   - UNCLEAR = صفر evidence.

5) decision.py:
   - ممنوع ACCEPT عند Gemini Visual UNCLEAR إذا تغيرت الحروف.
   - Generic ACCEPT يحتاج visual consensus قوي وفارق واضح لصالح candidate.

6) word_diacritics.py:
   - alignment < 0.72 -> REVIEW ولا إرسال Crop غير موثوق.
   - cache لنتائج التشكيل البصري.
   - Gemini لا يسمح له بتغيير الحروف.

7) rebuild_text.py:
   - الصورة الأصلية هي مصدر التشكيل عند status=OK.
   - لا يتم الحفاظ على تشكيل OCR القديم لمجرد وجود حركتين.
   - Preservation check للحروف والترقيم والمسافات والـlayout.
   - Word-sequence preservation check.

8) visual_diacritics.py:
   - تم إصلاح مشكلة retries التي كانت تجبر 5 محاولات على الأقل.
   - الحد الأقصى الآن محاولتان فقط للأخطاء المؤقتة.

9) TTS:
   - cache حسب text + model + voice + narrator.
   - فحص مدة الصوت لاكتشاف silence/repetition الشاذ.
   - عند مدة شاذة: إعادة توليد مرة واحدة فقط.
   - إذا فشلت الجودة مرة ثانية، لا يتم دمج/اعتماد الصوت.

10) run_full_pipeline.py:
   - Text-only final review معطل افتراضياً لتجنب regression وتوفير API.
   - إذا Diacritics REVIEW >= 50% يتم إيقاف TTS لهذه الصفحة لتجنب دفع API على نص غير موثوق.
   - يدعم حالات SUCCESS / REVIEW_REQUIRED / DIACRITICS_REVIEW_REQUIRED / FAILED.

ملاحظة مهمة:
هذا الفحص يضمن سلامة منطق الـPipeline والـguards وعدم وجود أخطاء Syntax في الملفات التي تم فحصها.
لا يمكن لأي نظام OCR/AI ضمان 100% أن كل كلمة ستخرج صحيحة من غير تشغيل على الصفحة ومقارنتها بالصورة/ground truth.
النسخة الحالية مصممة لتفضيل REVIEW/KEEP ORIGINAL على التخمين.
